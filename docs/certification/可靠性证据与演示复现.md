# ParaSure 可靠性证据与演示复现

## 交付前自检

运行：

```bash
./paramsure doctor
```

检查项：

- Python 版本。
- LLM 配置是否具备 `api_key`、`base_url`、`model`。
- 产品参数目录是否存在。
- Playwright Python 包是否可导入。
- Chrome CDP 地址是否配置。
- Web 证据目录是否可用。

该命令用于演示或交付前快速发现依赖问题，避免现场才暴露环境缺口。

## 脱敏证据统计

运行：

```bash
./paramsure evidence summary
```

输出内容：

- 会话文件数量。
- 会话事件数量。
- 工具调用观察数量。
- 工具失败数量。
- Web 证据包数量。
- 截图数量。
- 失败证据包数量。
- 使用过的工具名称。

该命令只输出统计摘要和工具名，不输出用户原始参数、客户名称、URL token 或页面正文，适合作为申报材料和复盘材料。

## 可复现演示路径

1. 查看产品参数库是否可索引：

   ```bash
   ./paramsure products
   ```

2. 运行脱敏样例核验：

   ```bash
   ./paramsure check examples/certification/客户参数样例.xlsx \
     --product "雷池- Web应用防火墙" \
     --out examples/certification/paramsure-result.xlsx
   ```

3. 查看输出矩阵：

   ```bash
   ls -lh examples/certification/paramsure-result.xlsx
   ```

4. 如有可访问演示环境，再运行只读 Web 验证：

   ```bash
   ./paramsure web-test "雷池- Web应用防火墙" \
     --requirement "用户登录支持对接SSO，至少支持CAS、OIDC协议的一种" \
     --requirement-id REQ-SSO-001 \
     --web-url "https://example.internal" \
     --cdp-url "http://127.0.0.1:9222"
   ```

5. 检查证据包：

   ```bash
   find .paramsure/artifacts/REQ-SSO-001 -maxdepth 1 -type f
   ```

   预期包含：

   - `evidence.json`
   - `page_excerpt.txt`
   - `screenshot.png`

## 质量口径

- 资料库强匹配：输出“资料已满足”，并给出来源文件、sheet、行号。
- 资料库弱匹配：输出“未确认”，提示需要演示环境或专家复核。
- Web 仅关键词命中：输出“未确认”，因为缺少可审计页面上下文。
- Web 关键词和上下文同时命中：输出“Web已确认”，并保留截图和证据 JSON。
- API 只读验证成功：可作为补充证据，但仍建议人工复核接口语义是否与参数原文一致。
